# Личная CRM

## Как запустить

### База данных (PostgreSQL в Docker)

1. Запустите Docker Desktop.
2. Если файла `.env` ещё нет, скопируйте `.env.example` в `.env` и заполните значения.
3. В папке проекта выполните:
   ```
   docker compose up -d
   ```
4. Проверить, что база работает:
   ```
   docker compose ps
   ```
   В колонке STATUS должно быть `healthy`.

Остановить базу: `docker compose stop`. Данные при этом сохраняются.

### Приложение

Нужны Node.js и pnpm. Перед первым запуском база должна работать (см. выше).

1. Установить зависимости:
   ```
   pnpm install
   ```
2. Создать таблицы в базе:
   ```
   pnpm db:migrate
   ```
3. (Необязательно) Наполнить базу тестовыми данными — 1000 контактов с заметками.
   Если в базе уже есть контакты, команда ничего не делает:
   ```
   pnpm db:seed
   ```
4. Запустить:
   ```
   pnpm build
   pnpm start
   ```
   Для разработки вместо этого: `pnpm dev`.
5. Открыть в браузере: http://localhost:3000

Строку подключения к базе приложение собирает из `POSTGRES_USER`, `POSTGRES_PASSWORD`,
`POSTGRES_DB` и `POSTGRES_PORT` в `.env`. Можно вместо этого задать `DATABASE_URL`.
